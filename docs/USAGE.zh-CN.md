# Web Ink

Web Ink 是本地优先的 Chrome 标注工具：网页文字、图片绘制，以及PDF 文字和区域标注。数据留在浏览器本机；没有账号、云同步或遥测。

[English](../README.en.md) · [隐私说明](../PRIVACY.md) · [第三方许可](../THIRD_PARTY_NOTICES.md) · [发布流程](RELEASING.md)

> 当前源码版本见 [package.json](../package.json)，实际安装版本和构建提交见设置页；公开下载包可能较早。本轮专注阅读与快捷标注见 [0.3.6 验证记录](VALIDATION-v0.3.6.md)，历史支持边界见 [验证记录](VALIDATION.md)，既有性能数据见 [测量报告](PERFORMANCE.md)。

## v0.3 的优化

- 文字选区和恢复共用当前页面的文字索引；保存后更新新增记录，正文变动时重新验证定位。
- 资料库每页最多 50 条，搜索保持完整子串匹配；输入变化立即取消旧任务，再防抖发起新查询。
- 已知长度 PDF 直接填入一个目标缓冲区；长文档只挂载可见页及相邻页，缩放和页面尺寸更新保留阅读位置。
- PDF 标注列表每次显示 50 条，可加载更多；编辑中的笔记跨列表重排保留，换文件前先保存或明确放弃。
- PDF 导出按需加载固定版本 pdf-lib；数据库仍为 v3、备份仍为 schema v2，无本轮数据迁移。

## 取消标注

- 网页：点击已有文字高亮或图片标记，在浮层选择 **取消标注**；重新选中已高亮文字也会出现该按钮。重叠标注按条选择，不会一次删除其它记录。
- PDF：点击已有高亮或区域标记，选择 **取消标注**。
- 网页和 PDF 取消后可在当前会话中撤销，原笔记、标签和颜色一起恢复。
- 资料库：打开记录，点击 **删除 → 确认删除**；确认在界面内完成，不依赖浏览器弹窗。
- 右下角总开关只控制显示与工具启用，不删除数据。

## 网页标注

- 右下角 40px 调色盘是当前网页的总开关：关闭时保持安静，不扫描正文、不绑定网页滚动/选区/MutationObserver，也不建立文本阅读索引。
- 每个 canonical URL 独立记忆开关；关闭只隐藏网页工具与标记，不删除记录。暂停的网站优先于页面开关。
- 开启后按需注入网页 engine。文字恢复使用 exact text、上下文、根/稳定容器验证；无法唯一确认时保持“未定位”，不猜测性绑定。
- 文字工具条先显示最近颜色、当前颜色和三个常用颜色；“更多”才展开全部颜色与自定义色。
- 图片选取阶段只显示提示；选中后才显示矩形、椭圆、箭头、画笔、颜色、撤销、重做和完成。图片与祖先的非恒等 CSS transform 会被拒绝。
- 侧栏、资料库和阅读器使用统一主题，可选系统/浅色/深色，并支持降低动效和降低透明度。悬浮按钮可以拖动，位置保存在本机；其他已打开网页不随之移动。

普通网页要求 Chrome 120 或更高版本。iframe、网页自身 Shadow DOM、浏览器内部页、file URL 与 canvas 内容不在网页标注范围内。

## PDF

打开 PDF 时，点击纸张右下角的悬浮笔按钮，再选择 **打开当前 PDF**。Web Ink 会在当前标签页切换到阅读器，并保留 **返回原阅读器**。再次点击笔按钮、点击菜单外部或按 Esc 可收起菜单；拖动仍用于调整按钮位置。网页的开启／关闭标注也在该菜单中。菜单中的 **选择电脑上的 PDF…** 会在新标签页打开仅含文件选择器的本地导入页，不显示公开网址输入框；通用阅读器仍提供公开 PDF 网址输入。菜单另有本篇标注和资料库入口。没有悬浮按钮时，可从 Chrome 工具栏打开 Web Ink 侧栏，选择 **在当前页开始标注**。多个可读来源需要先选择；IEEE 页面选择 **使用 IEEE 登录状态打开**，仅用同源实际来源读取；来源不可见时可读取受限包装页并检查它给出的嵌入地址，不猜下载链接。来源拒绝访问、需要跨站跳转或其他登录网站，请从原站下载后选择本地副本。此操作不修改默认 PDF 阅读器。

选中文字后，选区附近会出现颜色和笔记工具；选择颜色才保存高亮，普通复制不产生记录。**添加笔记**先保存高亮，再进入笔记编辑。保存失败保留选区或草稿并提供重试；跨页选区需要改为在单页内选择。**显示标注**控制已保存叠层，不妨碍创建新标注。旋转、区域标注、其他文件和资料库位于 **更多**。

使用阅读器内的返回、换文件或资料库入口时，未保存内容会提供 **保存并继续／放弃并继续／继续编辑**；保存失败留在当前文件。关闭或刷新标签页时，有未保存内容才触发浏览器的离开确认。浏览器强制退出或外部扩展 Reload 不能保证内存草稿保留，更新前请先保存。

PDF 支持基础文字标注与区域标注，坐标保存为未旋转页面坐标中的归一化值。PDF 页面需要 Chrome 125 或更高版本；最低版本由专门的 Chrome 125 CI 用例验证。

- 可从本地文件选择 PDF，或从明确授权的 HTTPS PDF 读者页面读取。
- 单个 PDF 输入上限为 **50 MiB**；该限制保护本地渲染和浏览器内存，不表示会存储文件内容。
- HTTPS 读取使用精确站点授权，并以 `credentials: 'omit'`、`cache: 'no-cache'`、`redirect: 'error'` 获取。每次打开都验证服务器版本；文件未变时可复用 Chrome 的 HTTP 缓存。重定向在 MVP 中被拒绝；请使用最终直接 PDF 地址，或下载后选择本地文件。
- 只保存 PDF 的 SHA-256、文件名、可选来源 URL、页码、文字锚点和区域几何；**Web Ink 数据库和备份不保存 PDF bytes**；公开 HTTPS 文件可能留在浏览器管理的 HTTP 缓存中，本地文件不会被缓存。
- 要恢复本地 PDF 标注和阅读位置，请重新选择原来的 PDF。文件内容变化时，旧标注仍保留，不会自动套用到新文件。
- 顶栏提供上一页／下一页、页码跳转、10%～500% 缩放输入、适合宽度、旋转和文内搜索；窄窗口把部分操作收进 **更多**。
- 使用 **⌘/Ctrl+F** 搜索 PDF 文字，Enter／Shift+Enter 切换结果，Esc 关闭搜索。搜索结果只是临时定位提示，不生成标注；扫描件没有文字时仍可使用区域标注。
- 缩放重画时保留上一幅完成的页面，直到新图像和文字层就绪；重画期间暂不接受基于旧文字位置的标注。
- 页码、页内位置、缩放和旋转按文件内容分别保存；已授权的公开来源刷新后可重新读取。本地文件仍需重选，文件字节不留存。阅读位置不进入 JSON 标注备份。
- 回程会话在浏览器重启或扩展 Reload 后可能失效；有公开来源时显示 **打开 PDF 来源**，本地文件提供重新选择入口。
- IEEE 登录读取是用户明确启用的例外：只在 `https://ieeexplore.ieee.org` 同源请求使用浏览器会话，禁用缓存与自动跳转，不读取 Cookie 值或密码。授权限于当前阅读器、十分钟内；换文件、离开、刷新或 Reload 后失效，返回 IEEE 后重新打开。临时下载票据不进入标注或备份。其他认证网站和密码加密 PDF 暂不支持；不提供 OCR 或修改原文件。
- IEEE 入口支持已打开的 PDF、stamp 包装页，以及实际嵌入同源 PDF 的论文页。只有论文信息或普通下载链接的页面，先在 IEEE 打开全文；不从文章编号猜下载地址。
- 从资料库点击 IEEE 标注的「打开 PDF」，优先进入已确认的 DOI 地址，再登录并通过 IEEE 的 PDF 入口取得全文，启用登录读取。新标注将明确的 PDF 元数据 DOI 保存为来源，因此 JSON 导出／导入后仍能使用。旧记录不改写：可通过本机的文件／论文索引找到 DOI；尚未确认 DOI 时返回稳定论文详情页，不从标题、文件名或文章编号猜 DOI，也不重放临时下载地址。旧包装页的恢复入口遵循同一规则。
- 阅读器和新标注优先显示 PDF 自带的论文标题及明确 DOI；元数据不可用时保留文件名。不会在线猜 DOI、改名磁盘上的文件，或自动改写旧标注的标题与摘录。
- Web Ink 按文件内容识别 PDF。同一份文件重开后恢复旧标注；从资料库发起的重新打开会在目标标签页内保留所选记录的页码提示，最多三十分钟且只使用一次。IEEE 下载件可能带有不同时间戳、水印等内容，因此同一 DOI 的文件也可能变化。此时不自动覆盖旧坐标，使用「查看之前的标注」直接进入旧文件的记录列表；旧记录和 JSON 保持完整。当前不支持跨版本重新绑定。论文索引与阅读偏好仅保存在本机，独立于 JSON 标注备份。

PDF renderer 使用 PDF.js `6.3.289` legacy build、同版本 worker 和随包资源。详见 [第三方许可](../THIRD_PARTY_NOTICES.md)。

## 原文件批注与 PDF 分享

打开 Preview 保存过的 PDF 后，原来的高亮、下划线、矩形和便签随原文件显示。在现有 Web Ink 侧栏选择 **原文件** 或 **全部** 阅读笔记；原文件批注标为只读，不会复制进资料库，也不能在 Web Ink 中编辑或删除。Popup 和回复归属于对应批注，不另列重复便签；不支持完整交互的类型会显示说明。

新增高亮、区域框和笔记后，从阅读器 **更多 → 导出带标注的 PDF…** 生成 `<原名>-annotated.pdf`。输出是独立文件，包含原批注以及当前文件全部已保存的 Web Ink 标注。接收者只需要这个 PDF。原文件不覆盖，JSON 备份和记录 ID 不改变；重复导出从原文件重新生成。再次打开导出件时，内嵌标注作为原文件只读批注显示，不重复套用旧文件的本机高亮。

有未保存修改时先保存、放弃或继续编辑。导出失败保留本机记录；“已生成并开始下载”表示浏览器已接到下载请求，仍需检查下载位置。加密、数字签名、禁止注释权限、XFA、破损或超过 50 MiB 的 PDF 不支持此导出方式。部分阅读器对颜色、便签或回复的显示方式不同；实际验收范围见验证记录。

**更多 → 导出给 AI** 下载当前文件的独立 JSON 笔记快照，包含 Web Ink 记录及原文件笔记、页码、来源和可读取的时间；没有原文摘录或时间的批注不编造这些信息。此文件使用 `web-ink-pdf-notes` v1，不能当作资料库备份导入。只读 skill 可查询它；普通资料库 JSON 备份格式保持不变。快照上限 20 MiB、50,000 条记录，导出不会上传到模型或外部服务。

## 存储、备份与升级

网页/PDF 标注保存在扩展拥有的 IndexedDB；设置保存在 `chrome.storage.local`。资料库可按关键词、类型、颜色和标签筛选，并显示逻辑记录大小与浏览器占用估算。

- 备份 schema v2 兼容导入 schema v1；导入前验证，按 ID 合并，冲突默认保留本地记录。
- 网页和 PDF 元数据都进入 JSON 备份；PDF 原始 bytes 从不进入备份。
- 备份与输入容量由界面和验证层限制；以实际发布版本的提示为准，不能把逻辑大小当作物理磁盘占用。
- 升级请保留稳定的解压安装目录，在 `chrome://extensions` 使用 **Reload**，不要卸载。manifest 的稳定 public extension ID 使 Reload 可保留扩展本地存储；卸载会删除本地数据。
- 更新、清理浏览器数据、切换 profile 前先导出 JSON 备份。

## 专注阅读与快捷标注（0.3.6）

PDF 阅读器的 **更多 → 专注阅读** 收起顶栏；底部胶囊保留翻页、查看标注和退出。点击退出或在阅读控件上按 Esc 恢复顶栏，不改变缩放或文档。未保存笔记需要先处理。Chrome 不支持或拒绝自动关闭侧栏时，会提示手动关闭；这不是浏览器全屏模式。

选中文字后，点击 **重要／疑问／精彩** 保存对应颜色和标签；也可按 `Alt+Shift+1` 至 `Alt+Shift+5`。快捷键仅作用于当前有效文字选区，输入框、笔记编辑器和弹窗中不生效。普通选字、复制不保存标注，原有五色和自定义颜色操作继续可用。

从 **设置与数据 → 标注预设…** 或阅读器 **更多 → 标注预设…** 修改名称、颜色，最多五个。预设只保存在当前浏览器，不属于标注记录或 JSON 备份；不同窗口同时编辑时以最后成功写入为准。保存失败保留草稿，可再次尝试。更新不会改写已有记录的颜色、标签或笔记。

浮动控件可使用轻量透明材质；系统或产品的“减少透明度／减少动态效果”会选择纯色或关闭动画。正式安装目录同步和用户 Chrome 实际 Reload 生效分别记录，自动化通过不代替人工验收。
