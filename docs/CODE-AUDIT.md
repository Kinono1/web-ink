## 安全边界

- **A01 / A07** 站点脚本经浏览器标识的发送者、顶层文档和规范页面 URL 访问该页数据。资料库、整库备份及设置写入要求扩展上下文。PDF Port 和交接分别校验入口、标签页或会话。 [Chrome 消息安全建议](https://developer.chrome.com/docs/extensions/develop/concepts/messaging#security-considerations)
- **A02 / A05** Manifest 将站点访问声明为可选权限。扩展页面限制脚本来源，PDF.js 原生注解层限制链接和显示数据，并关闭表单及脚本。IEEE wrapper 在惰性模板中读取资源属性并重新验证 URL。 [扩展配置](../wxt.config.ts) · [PDF 注解处理](../src/pdf/native-annotations.ts) · [IEEE 读取](../src/core/ieee-reader.ts)
- **A03 / A08** 基线 npm 全量审计报 3 个 High 和 3 个 Moderate 包告警，涉及 Vite、Undici、source-map-js 和 Vitest 工具链。更新 Vitest 与覆盖率插件到 5.0.3，锁文件更新 Vite 至 8.3.8、Undici 至 8.12.4、source-map-js 至 1.2.3。生产依赖审计基线为 0。跟踪文本的常见私钥和令牌模式未命中。Manifest 的 `key` 用于扩展公开身份，私钥路径由 Git 忽略规则覆盖。运行包用文件清单和 SHA-256 封存。 [npm audit](https://docs.npmjs.com/cli/audit/) · [OWASP 供应链](https://top10.owasp.org/2025/A03_2025-Software_Supply_Chain_Failures/) · [发布流程](RELEASING.md)
- **A04 / A06 / A10** 标注及备份依赖本地浏览器和文件访问控制。普通在线 PDF 仅用无凭据 HTTPS，IEEE 的凭据请求限定已授权的源。导入和 PDF 输入有大小边界，事务失败保留先前数据。 [隐私说明](../PRIVACY.md) · [PDF 字节读取](../src/core/pdf-source.ts) · [备份事务](../src/background/data/backup.ts)
- **A09** 后台存储、路由和注册的意外失败只记录固定操作名和错误码。PDF 会话保留自己的可恢复诊断。 [后台错误出口](../src/background/request-result.ts) · [OWASP 日志与告警](https://top10.owasp.org/2025/A09_2025-Security_Logging_and_Alerting_Failures/)

依赖告警以审查时 npm 返回的数据为准。应用安全结论来自代码、权限配置和本地回归。真实登录站点与发布环境的外部测试仍待验证。 [OWASP Top 10:2025](https://top10.owasp.org/2025/0x00_2025-Introduction/)
